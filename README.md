# Sistema SOS Centralizado — Presentación

Presentación interactiva del proyecto **Sistema SOS Centralizado**: una app de seguridad personal donde el celular solo dispara y un backend centralizado hace todo el trabajo pesado.

🎬 **[Ver presentación en vivo](https://jaydethsp01.github.io/sistema-sos-presentacion/)**
