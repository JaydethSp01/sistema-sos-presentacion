# ShakeSOS — Presentación

Presentación interactiva de **ShakeSOS**: una app de seguridad personal donde el celular solo dispara —sacudiéndolo o presionando un botón— y un backend centralizado hace todo el trabajo pesado.

> *Sacude el celular. Avisa a quien te quiere.*
>
> *Si algo te pasa, alguien lo sabrá. Siempre.*

🎬 **[Ver presentación en vivo](https://jaydethsp01.github.io/sistema-sos-presentacion/)**
